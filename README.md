# Somatologie

**Verze: 1.2.0**  
**Datum vydání: 18. 10. 2026**  
**Počet otázek: 150**

Mobilní procvičování somatologie v jednom samostatném HTML souboru. Obsahuje vysvětlení odpovědí, chytré opakování a ukládání pokroku v prohlížeči.

## Změny v této verzi

- Přidáno 50 otázek, čísla 101–150, včetně vysvětlení a pomůcek pro zapamatování.
- Všech 150 správných odpovědí porovnáno s tištěnými klíči zdrojového PDF. Nejednoznačné formulace mají poznámku u odpovědi.
- Původních 100 otázek zůstalo beze změny.
- Ověřeno mobilní zobrazení, výsledky a chytré opakování.
- Ověřeno zachování chyb, tipů, zvládnutých otázek a rozpracovaného kola po aktualizaci i zavření a znovuotevření prohlížeče.
- Vydání je nově dodáváno ve verzované složce společně s tímto README.

## Spuštění a nahrání

Otevři `index.html` v prohlížeči. Stažený soubor funguje bez internetu.

Na GitHub nahraj **obsah této složky** do stejného místa jako dosud: `index.html` a `README.md`. Název vydané složky slouží pro archivaci; kvůli nové verzi není potřeba měnit adresu webu.

Pokrok se ukládá po každé odpovědi v konkrétním prohlížeči a jeho profilu, odděleně od HTML souboru. Nahrazení aplikace na stejném webu ho zachovává, pokud zůstala zachovaná data prohlížeče. Mezi zařízeními se nesynchronizuje; vymazání dat nebo ukončení anonymního režimu může pokrok odstranit.
